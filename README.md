## Installation

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher)
- [npm](https://www.npmjs.com/) package manager

### Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/username/auto-readme.git
cd auto-readme
```

2. Install dependencies:

```bash
npm install
```
